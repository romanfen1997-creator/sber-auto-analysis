# Анализ поведения пользователей сайта «СберАвтоподписка»

Личный проект по продуктовой и маркетинговой аналитике. На данных Google Analytics исследую, как источники трафика, устройства, география и интерес к автомобилям связаны с конверсией в целевые действия на сайте «СберАвтоподписка».

**Стек:** Python 3.12, pandas, Matplotlib, missingno, statsmodels, Jupyter Notebook.

**[Открыть ноутбук с кодом, графиками и выводами](notebooks/sber_auto_analysis.ipynb)**

В ноутбуке сохранены результаты выполнения: таблицы, графики, статистические тесты и выводы. Для знакомства с проектом скачивать исходные данные и запускать код не требуется.

## Задача

Определить, какие сегменты трафика дают целевые действия, проверить различия конверсии между группами и подготовить рекомендации для продуктовой команды. При оценке сегментов учитываю конверсию, объём трафика и количество целевых действий.

## Данные и метрика

Исходные данные состоят из двух таблиц, связанных по `session_id`. Файлы хранятся отдельно на Google Drive и не включены в репозиторий из-за большого объёма. Они нужны для повторного запуска анализа.

| Таблица | Единица наблюдения | Количество строк | Количество столбцов |
|---|---|---:|---:|
| `ga_sessions` | Визит на сайт | 1 860 042 | 18 |
| `ga_hits` | Событие внутри визита | 15 726 470 | 11 |

Основная метрика **Conversion Rate (CR)** рассчитывается как доля сессий, в которых произошло хотя бы одно целевое событие. В список входят восемь действий, включая клик по заявке, открытие диалога, запрос обратного звонка и успешную отправку формы. Несколько целевых событий внутри одной сессии учитываются как одна конверсионная сессия.

События агрегируются до уровня сессии, затем присоединяются к таблице визитов. Сессии без найденного целевого события получают `has_conversion = 0`.

## Что сделано

1. Проверены типы данных, пропуски, дубликаты и уникальность ключей. Обработаны даты и категориальные значения.
2. Сформирована аналитическая таблица с одной строкой на сессию и признаком конверсии.
3. Проведён разведочный анализ трафика и CR по источникам, кампаниям, устройствам, городам и моделям автомобилей.
4. Проверены три гипотезы двусторонним z-тестом для двух долей при уровне значимости `alpha = 0.05`.
5. Сопоставлены статистическая значимость, размер различий и объём сегментов. Подготовлены рекомендации для бизнеса.

## Основные результаты

Из **1 860 042 сессий** в **50 314** произошло хотя бы одно целевое действие. Общий CR составил **2,70%**.

| Сравнение | CR первой группы | CR второй группы | Разница, п.п. | p-value |
|---|---:|---:|---:|---:|
| Organic / Paid | 4,04% | 2,19% | +1,84 | < 0,001 |
| Desktop / Mobile | 3,14% | 2,60% | +0,54 | < 0,001 |
| Города присутствия / Остальные регионы | 2,80% | 2,60% | +0,19 | < 0,001 |

Разницы рассчитаны по исходным долям до округления. В анализе в группу `organic` включены `utm_medium` со значениями `organic`, `referral` и `(none)`, остальные значения относятся к `paid`. Эта группировка шире органического поискового трафика. Города присутствия включают Москву, Санкт-Петербург и найденные в данных города Московской области; неопределённый регион исключён из соответствующего теста.

Дополнительные выводы:

- **Mobile даёт 79,29% сессий**, поэтому мобильный пользовательский путь важен даже при более низком CR.
- **Трафик из социальных сетей даёт 14,74% сессий и 7,99% конверсий.** Его CR составляет 1,47% против 2,92% у остального трафика.
- По количеству сессий с просмотром автомобиля лидируют **Skoda Rapid, Lada Vesta и Volkswagen Polo**.
- Разница CR по регионам составляет около **0,19 п.п.** Бизнес-значимость этого различия следует оценивать отдельно от статистической значимости.

## Как воспроизвести анализ

Инструкция ниже предназначена для полного пересчёта результатов. Для просмотра сохранённых таблиц, графиков и выводов достаточно открыть ноутбук по ссылке выше.

Ноутбук подготовлен в **Python 3.12.3**. Для запуска нужны исходные данные и локальное Python-окружение.

### 1 Скачать репозиторий

```bash
git clone https://github.com/romanfen1997-creator/sber-auto-analysis.git
cd sber-auto-analysis
```

### 2 Создать виртуальное окружение

В Linux, WSL или macOS с установленным Python 3.12:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

В Windows PowerShell с установленным Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3 Установить зависимости

```bash
python -m pip install -r requirements.txt
python -m pip install jupyterlab
```

JupyterLab устанавливается отдельно, поскольку не включён в текущий `requirements.txt`.

### 4 Подготовить данные

Для полного пересчёта потребуются исходные таблицы Google Analytics, которые хранятся на Google Drive. Если файлы упакованы в ZIP, предварительно распакуйте архив.

Создайте каталог `data/raw` в корне проекта и поместите в него таблицы сессий и событий. После распаковки файлы должны находиться непосредственно в `data/raw`, без дополнительной вложенной папки `data`. Ноутбук поддерживает следующие варианты:

| Таблица | CSV | Pickle |
|---|---|---|
| Сессии | `data/raw/ga_sessions.csv` | `data/raw/ga_sessions.pkl` |
| События | `data/raw/ga_hits-002.csv` | `data/raw/ga_hits.pkl` |

Для каждой таблицы достаточно одного из двух форматов. Если файл `.pkl` существует, ноутбук использует его в первую очередь; иначе читает CSV. Обратите внимание на точное имя CSV с событиями: **`ga_hits-002.csv`**.

### 5 Открыть ноутбук

```bash
jupyter lab
```

Откройте `notebooks/sber_auto_analysis.ipynb`, выберите ядро созданного окружения и выполните ячейки последовательно. Пути к данным в коде заданы относительно каталога `notebooks` через `../data/raw`.

## Ограничения интерпретации

Результаты описывают связи в исторических данных. Дополнительный эффект изменения рекламы или интерфейса нужно проверять отдельным экспериментом. Данных о расходах на рекламу и выручке в анализе нет, поэтому выводы относятся к конверсии и структуре трафика, без оценки ROI.

Единица анализа и статистических сравнений здесь сессия. Повторные визиты одного пользователя могут быть зависимыми, что следует учитывать при интерпретации p-value. Часть источников и кампаний представлена закодированными идентификаторами; неопределённые города не используются для географических выводов.
